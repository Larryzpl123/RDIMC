# RDIMC: Rotational Dynamics in Motor Cortex

An interactive 3D demo of jPCA, showing how motor cortex population activity rotates during reaching, built for a Linear Algebra class project. It compares a synthetic linear model with real monkey data (the jPCA code pack from Churchland et al. 2012, and the MC_Maze session on DANDI 000128).

Live demo: https://larryzpl123.github.io/RDIMC/
